## 📋 Version Check Procedure

Before every major build phase, run these checks:

| Step | Action | Tool/Command |
|---|---|---|
| 1 | Check all package versions | `npm outdated` or equivalent |
| 2 | Verify compatibility between packages | Check official docs / changelogs |
| 3 | Search for known issues | Web search: "[library] [version] breaking changes" |
| 4 | Test core functionality | Run existing tests after any update |
| 5 | Update this file | Log all findings here |
